# CreatorCut v0.1.0-rc.1

This is the first immutable release candidate for CreatorCut M1, the public
local-execution client for intelligent post-production of talking-head and
product-screen-recording videos.

## Included

- local media import, durable project state, timeline history, undo and redo;
- local Chinese, English and mixed-language transcription through whisper.cpp;
- signed Director decision cards, cost quote, review plan and edit manifest;
- fail-closed 50-credit planning flow through AgentMesh Core;
- transactional local preview, apply and export with recoverable task state;
- original audio, clean captions, no-filter output and two approved upbeat
  background-music templates;
- Codex MCP App, OpenClaw Skill and generic text-host interaction adapters;
- recovery-root-signed release policy, managed macOS installation and rollback.

## RC acceptance

The candidate is promoted to `v0.1.0` only after the frozen Cycle 5 gates pass:

1. clean installation through the signed staging ReleaseManifest;
2. real Job Agent, Codex and FocuSee source-video dogfood covering Chinese,
   English and mixed-language speech;
3. exact Director signatures and 50-credit ledger evidence;
4. export playback approval, failure compensation and rollback drill;
5. dark production deployment and owner-only paid canary.

No production stable channel is activated by this RC tag.
