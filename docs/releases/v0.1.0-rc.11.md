# CreatorCut v0.1.0-rc.11

This candidate supersedes `v0.1.0-rc.10` after the real three-material repeat
export gate found that the 2160×3840 Codex HLG output retained the accepted
color and audio properties but did not reproduce the prior file SHA-256.

## Deterministic export correction

- Pin each media input to one FFmpeg decode thread.
- Pin simple and complex filter-graph scheduling to one thread so scaling,
  subtitles and floating-point audio filters do not depend on host scheduling.
- Keep x265 WPP multi-core encoding, but pin frame-level and lookahead
  scheduling to one thread.
- Preserve HEVC Main 10, `hvc1`, `yuv420p10le`, BT.2020 and HLG metadata.
- Preserve the RC9 original-color path and the RC10 absolute Node.js 24 managed
  launcher.

## PDCA evidence

- RC10 JobAgent and FocuSee repeat exports matched the accepted files
  byte-for-byte.
- The RC10 Codex repeat retained 2160×3840 HEVC Main 10, HLG/BT.2020 and the
  exact duration. Its decoded audio comparison measured more than 162 dB PSNR,
  and decoded video measured 0.997785 overall SSIM, but the different file
  digest still failed `TC-PUBLIC-005`.
- A parallel six-second 4K HLG probe containing real cuts, subtitles, original
  audio and the accepted music chain produced the same SHA-256 in both outputs
  after decode, filter and frame/lookahead scheduling were pinned.
- Named media-engine regression coverage locks the deterministic arguments and
  original-color metadata contract.

## Release status

- RC11 must repeat full public verification, canonical archive validation,
  signed staging installation and all three real-material exports.
- Staging commercial gates remain closed while RC11 is prepared.
- No stable release or production activation is authorized by this candidate.
