# CreatorCut v0.1.0-rc.2

This candidate supersedes `v0.1.0-rc.1` for Cycle 5 staging acceptance.

## Fixed since rc.1

- The public macOS installer now invokes the frozen `pnpm@10.30.3` explicitly.
  A completely new HOME can no longer inherit a newer global Corepack pnpm and
  fail the project's package-manager version gate.
- Managed `creatorcut update apply` uses the same explicit pnpm version, keeping
  first installation, update and rollback builds on one runtime contract.
- The installer still verifies the recovery-root-signed keyset, signed Core
  ReleaseManifest, exact tag, commit and canonical source archive before
  executing release code.

All M1 functionality and remaining Cycle 5 acceptance gates are unchanged from
`v0.1.0-rc.1`.
