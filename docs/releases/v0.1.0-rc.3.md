# CreatorCut v0.1.0-rc.3

This candidate supersedes `v0.1.0-rc.2` for Cycle 5 staging acceptance.

## Fixed since rc.2

- First installation changes into the verified checkout before dependency or
  build commands. Managed update already executes with that checkout as its
  process working directory.
- Both paths ask Corepack's explicit `pnpm@10.30.3` process to build the 12
  application/package workspaces while excluding the recursive root package.
- The build no longer enters the root `build` script and then depends on a
  second unqualified `pnpm` executable being present in Corepack's isolated
  process PATH.
- The public contract test rejects both an unpinned pnpm invocation and the
  nested root-build form that failed clean-home acceptance.

The release trust chain, M1 product scope and remaining Cycle 5 acceptance gates
are unchanged.
