# CreatorCut v0.1.0-rc.5

This candidate supersedes `v0.1.0-rc.4` for Cycle 5 staging acceptance. It is
not a stable or production release.

## Fixed since rc.4

- Director finalization now polls with a bounded retry window until the signed
  Manifest is ready instead of attempting to verify a missing asynchronous
  result.
- Replaying the exact confirmed ReviewDecisionSet is idempotent after
  finalization; a changed decision set still fails closed.
- The signed Manifest now requires a bounded finishing intent for caption
  style, LUT, original/voice mode, and the two approved local upbeat music
  templates.
- The public client deterministically materializes finishing assets locally,
  binds project, timeline and EditBrief digests to the preview, and commits only
  the exact confirmed result.
- Original speech remains the primary track. Background music uses local
  synthesis, fade-in/out, voice-driven sidechain ducking, loudness
  normalization and limiting.
- HLG and PQ sources are tone-mapped to tagged BT.709 output before any
  optional LUT. No look filter is applied when `lut_none` is selected.
- Chinese, English and mixed transcription caches now bind source, model,
  language mode and glossary. `transcribe show` and `transcribe replace` support
  human correction before Director consent.
- Caption rendering uses a system sans-serif family for CJK fallback and keeps
  clean and bold styles distinct.

## Acceptance status

- Public and private repository quality gates pass locally.
- A real 3840×2160 HLG Job Agent source rendered locally at its original
  53.338-second duration with BT.709 output and original speech plus local
  `light_tech` music.
- Staging and production activation remain gated. Three-material paid staging
  dogfood and user continuous listening are still required before stable.
