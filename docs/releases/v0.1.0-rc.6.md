# CreatorCut v0.1.0-rc.6

This candidate supersedes `v0.1.0-rc.5` after the real long-form Codex dogfood
proved that a valid 90 KB DirectorContext could be rejected by the private
Server's legacy 64 KB HTTP parser limit.

## Compatibility correction

- The private Director Server now accepts the public protocol's advertised
  4 MiB request ceiling, so longer bilingual transcripts reach protocol
  validation and authorization instead of failing in the HTTP parser.
- Oversized requests fail explicitly with HTTP 413 and
  `payload_too_large`; they are no longer converted to a generic HTTP 500.
- No public protocol schema or protocol bundle digest changed from RC5.

## Release status

- The RC5 staging dogfood stopped before quote confirmation or debit.
- Staging commercial gates were closed immediately after the failure.
- RC6 must repeat the official installer smoke and all three real-material
  staging Generations before stable release work may begin.
