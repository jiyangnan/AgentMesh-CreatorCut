# CreatorCut v0.1.0-rc.7

This candidate supersedes `v0.1.0-rc.6` after the three-material staging
dogfood found that the final mixed audio bus used a looser limiter ceiling than
the already approved CreatorCut music pipeline.

## Audio safety correction

- The final original-voice plus background-music mix now uses the approved
  `0.89` limiter ceiling instead of `0.95`.
- The no-music output path uses the same safe ceiling.
- The two approved upbeat templates, Director decisions, signed Manifests,
  transcript data and edit operations are unchanged.
- A regression test inspects the compiled FFmpeg filter graph and rejects a
  return to the unsafe `0.95` final limiter.

## Release status

- RC6 staging Generations and their 50-credit receipts remain valid because
  this correction changes only local client rendering.
- RC7 must repeat the signed installer smoke and rerender all three confirmed
  Manifests before any stable release work may begin.
