# CreatorCut v0.1.0-rc.8

This candidate supersedes `v0.1.0-rc.7` after three-material acceptance found
that FFmpeg's `alimiter` enables automatic level compensation by default. That
default raised the limited signal back toward full scale and allowed AAC true
peaks to reach 0 dBFS.

## Audio safety correction

- Every final `0.89` limiter now explicitly sets `level=false`, so the ceiling
  is retained instead of being offset by automatic level compensation.
- The original-voice plus background-music path and the no-music path use the
  same fail-closed limiter behavior.
- The two approved upbeat templates, Director decisions, signed Manifests,
  transcript data and edit operations are unchanged.
- The regression test requires the explicit `level=false` setting and rejects
  both an omitted auto-level setting and the former `0.95` ceiling.

## PDCA evidence

- RC7 retained the intended duration, picture, framing and BT.709 color, but
  FocuSee and Codex measured approximately 0.0 and +0.1 dBFS true peak.
- A local AAC probe with `alimiter=limit=0.89:level=false` measured
  approximately -0.9 dBFS for FocuSee and -0.8 dBFS for Codex.
- RC8 must repeat the full public verification, remote tag/archive install,
  signed Manifest rerender and three-material media checks before apply.

## Release status

- Existing staging Generations and their 50-credit receipts remain valid
  because this correction changes only deterministic local rendering.
- No stable release or production activation is authorized by this candidate.
