# CreatorCut v0.1.0-rc.9

This candidate supersedes `v0.1.0-rc.8` after three-material visual acceptance
found that `lut_none` still allowed the local renderer to apply an implicit
HLG/BT.2020-to-SDR/BT.709 conversion.

## Original-color correction

- Remove the implicit `zscale`, Hable tone-map, desaturation and forced BT.709
  output path.
- Preserve a uniform source color profile in the rendered output. HLG/BT.2020
  material remains HEVC Main 10 with 10-bit pixels, HLG transfer and BT.2020
  primaries; SDR BT.709 material remains SDR BT.709.
- Refuse mixed source color profiles instead of silently converting them.
- Keep explicit user-selected LUT effects available, but apply no creative LUT
  when the signed timeline contains `lut_none`.
- Preserve the already accepted original voice, upbeat background music,
  captions, edit operations, framing and audio limiter.

## PDCA evidence

- The Plan/Check comparison confirmed that the prior `lut_none` contract meant
  only “no creative LUT” while an automatic color conversion still ran during
  render.
- Named regression tests reject `zscale`, tone-map, desaturation, forced
  BT.709 and mixed-profile conversion in the default path.
- Real Job Agent and Codex outputs retain HEVC Main 10, `hvc1`,
  `yuv420p10le`, BT.2020 and HLG metadata. The real FocuSee output retains
  H.264, `yuv420p` and BT.709 metadata.
- The three original-color outputs passed user visual acceptance on
  2026-07-28.

## Release status

- Existing staging Generations and their 50-credit receipts remain valid
  because this correction changes only deterministic local rendering.
- RC9 must repeat the public verification, canonical archive/install checks,
  signed Manifest rerender and three-material media checks before stable.
- No stable release or production activation is authorized by this candidate.
