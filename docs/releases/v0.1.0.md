# CreatorCut v0.1.0

CreatorCut M1 is the public local-execution Agent for intelligent
post-production of talking-head videos and product screen recordings.

## M1 capabilities

- Chinese, English and mixed-language local transcription through whisper.cpp.
- Signed Director cards and edit plans with explicit preview and confirmation.
- Reversible local timeline operations, captions and original-audio-first
  rendering.
- Two approved upbeat local background-music templates.
- Source-color preservation for SDR BT.709 and HLG/BT.2020 material, with no
  implicit tone mapping or creative LUT.
- Repeatable HLG exports through pinned decode, filter and x265 scheduling.
- macOS managed installation with a pinned Node.js 24 runtime, signed Core
  ReleaseManifest, exact tag/commit/archive verification, safe update deferral
  and rollback.

## Product boundary

- Public `AgentMesh-CreatorCut` owns local media, safe execution and host
  adapters.
- Private `creatorcut-server` owns Director strategy, interactive-card
  orchestration, signed plans and billing recovery.
- Shared `agentmesh-core` owns identity, entitlements, action price, credits and
  release policy.
- `agentmesh-deploy` owns deployment operations and shared Caddy integration.

## Activation status

The stable tag is an immutable release carrier, not the final launch switch.
Production must deploy dark/gated, the approved paid canary and rollback must
pass, and Core stable ReleaseManifest activation remains the final public
availability action.
