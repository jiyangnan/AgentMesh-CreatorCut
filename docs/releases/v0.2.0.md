# AgentMesh-CreatorCut v0.2.0

This release turns the completed M1 local client into an AgentMesh360-style
product install: one command, explicit platform support, managed dependencies,
safe credentials, signed upgrades, and rollback.

## User-visible changes

- macOS 14+, Ubuntu 22.04/24.04, and native Windows 10 22H2/11 are supported.
- The installer owns the pinned Node.js 24 runtime, pnpm 10, Git,
  FFmpeg/FFprobe, whisper.cpp, and the verified multilingual Whisper model.
- API keys use macOS Keychain, Windows current-user DPAPI, or Linux Secret
  Service and never enter the command line.
- `creatorcut update apply` supports every GA platform while preserving project
  media, `.creatorcut` state, task checkpoints, and API keys.
- The public name is consistently **AgentMesh-CreatorCut**. The compatible CLI
  command remains `creatorcut`; internal service and protocol identifiers are
  unchanged.
- The bilingual product website publishes the exact install commands, supported
  platforms, privacy boundary, and authoritative 50-credit Director price.

## Compatibility

- CreatorCut Protocol v1 is unchanged.
- Existing M1 projects and signed plans remain readable.
- The release does not add automatic color correction, filters, LUTs, or
  tone-mapping. Original-color export remains the default.
- Local transcription, editing, captions, music, preview, export, undo, and
  redo do not consume credits.

## Activation gate

The immutable public release is the carrier, not the cloud launch switch. The
cloud Director is opened only after the macOS/Ubuntu/Windows matrix, clean
managed installation, signed ReleaseManifest, paid 50-credit canary, refund
drill, and rollback checks pass.
