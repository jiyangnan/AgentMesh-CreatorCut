# AgentMesh-CreatorCut v0.2.1

This patch release completes the journey after one-command installation. The
website now places the macOS terminal command directly beside the install call
to action, while the managed installer hands control to a resumable,
Agent-native onboarding command.

## User-visible changes

- `creatorcut onboard` resumes at the first incomplete stage: environment
  repair, secure login, local recording import, multilingual transcription,
  explicit Director-context consent, or Director start.
- macOS, Ubuntu, and Windows managed installers pin and verify the public
  production Director endpoint, Protocol v1 digest, keyset, and recovery roots.
- The website shows the macOS terminal command immediately below the primary
  install action instead of sending users to the bottom of the page.
- The detailed install section explains the four post-install stages and keeps
  the Windows PowerShell command available.

## Compatibility

- CreatorCut Protocol v1 and existing `.creatorcut` projects are unchanged.
- The API key still enters through standard input and remains in the
  platform-native credential store.
- Source media and local transcript files remain on the user's device.
- Original-color export remains the default; no filters or automatic color
  processing are added.
