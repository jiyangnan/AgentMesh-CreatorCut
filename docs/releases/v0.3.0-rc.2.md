# AgentMesh-CreatorCut v0.3.0-rc.2

This release candidate fixes customer-facing CLI guidance discovered by an
independent black-box run on a separate Intel Touch Bar Mac. It does not widen
the supported platform matrix or activate internal-project migration.

## User-visible changes

- `creatorcut --version` now returns the same stable JSON response and exit
  status as `creatorcut version`.
- `creatorcut doctor` now discovers `ffmpeg`, `ffprobe`, and `whisper-cli` from
  the current `PATH` when no managed path is configured. An explicitly
  configured but invalid path still fails closed and is never hidden by a PATH
  fallback.
- Projects missing any required local transcription dependency now return
  `requires_user_action: true`, a clear diagnostic prompt, and the executable
  `doctor` recovery step instead of suggesting a transcription command that
  must fail.
- Project-scoped follow-up actions now include structured `next_argv` and
  `next_process` fields. Agents starting a new process must invoke the exact
  executable, argv, and cwd from `next_process`, merge its non-secret
  `env_overrides` into the host environment, and keep `shell: false`, including
  on Windows. The human-readable `next_suggested` field uses a non-interpolated
  `PROJECT_DIRECTORY` placeholder.
- The supported OpenClaw host now receives `next_openclaw`, an exact exec-tool
  contract using the fixed `creatorcut __openclaw-bridge` command and
  structured environment argv. Non-secret cards/finalize JSON uses a bounded,
  no-echo PTY line; API-key entry remains manual and never enters an Agent tool
  call. After private-terminal login, structured `auth status` resumes the same
  project-scoped `onboard` flow. The v0.3.0-rc.2 CLI and OpenClaw Skill are a
  matched pair: until the
  matching Skill is published through ClawHub, install it from the same
  verified RC archive. Old OpenClaw Skills fail closed before project access
  instead of executing display-only continuation text. Replace an existing
  default-agent Skill from the unpacked archive with
  `openclaw skills install ./skills/openclaw-creatorcut --as creatorcut --force`.
- The public CLI filters only Node 24's expected `node:sqlite` experimental
  warning, keeping the JSON channel's stderr clean without suppressing other
  warnings.

## Compatibility and boundaries

- The managed-install support matrix remains macOS 14 or newer, Ubuntu 22.04
  or 24.04, and Windows 10 22H2 or Windows 11. A source build succeeding on an
  older operating system does not create a managed-support commitment.
- v0.2.1 public-project adoption and its byte-preservation guarantees are
  unchanged.
- `project migrate-internal` and `project rollback-internal` remain disabled.
  The native whole-tree swap implementation remains an unshipped synthetic
  prototype.
- No real project, media, credential, Director request, upload, or paid action
  was used for the independent customer run or these regressions.
