# AgentMesh-CreatorCut v0.3.0-rc.3

This release candidate fixes two local-dependency diagnostics found by a
customer-style Codex acceptance run on a separate Apple Silicon Mac mini. It
does not widen the supported platform matrix or activate internal-project
migration.

## User-visible changes

- `creatorcut doctor` and `creatorcut onboard` now honor explicit `--ffmpeg`,
  `--ffprobe`, `--whisper`, and `--model` paths. CLI values take precedence
  over their environment variables; FFmpeg, FFprobe, and whisper.cpp use
  `PATH` only when neither explicit source is configured, while the model must
  be an explicitly configured readable file.
- An explicitly configured empty executable path now reports `ready: false`
  instead of silently falling back to a similarly named command on `PATH`.
- A dependency option without a value now returns stable `invalid_input`
  before CreatorCut reads stdin, stores a credential, resolves or creates a
  project, opens a Director adapter, or starts a media operation.
- Structured `doctor`, `onboard`, transcription, and authentication
  continuations preserve all four non-secret dependency overrides. After a
  private-terminal login, the matching OpenClaw Skill changes only
  `auth login` to `auth status`; the project and dependency arguments remain
  byte-for-byte unchanged.
- The v0.3.0-rc.3 CLI and OpenClaw Skill remain a matched pair. Until the
  matching Skill is published through ClawHub, replace the existing Skill from
  the same verified RC archive with
  `openclaw skills install ./skills/openclaw-creatorcut --as creatorcut --force`.

## Compatibility and boundaries

- The managed-install support matrix remains macOS 14 or newer, Ubuntu 22.04
  or 24.04, and Windows 10 22H2 or Windows 11.
- v0.2.1 public-project adoption and its byte-preservation guarantees are
  unchanged. Projects already opened by v0.3.0-rc.1 or v0.3.0-rc.2 remain
  compatible.
- `project migrate-internal` and `project rollback-internal` remain disabled.
- The independent customer run used synthetic project data and performed no
  Director request, media upload, paid action, credential write, or credential
  deletion.
