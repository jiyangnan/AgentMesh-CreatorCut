产品录屏剪辑指南

产品录屏的重点，是让观众跟得上每一步。

等待、跳转、鼠标移动、口播解释和界面反馈共同决定演示节奏。剪得太慢会拖沓，剪得太快又会让用户不知道刚才发生了什么。

一条清楚的产品录屏，通常有四段

问题与结果

先用一句话说明用户遇到什么问题，以及接下来会看到什么结果。不要从登录页和无关准备动作开始。

最短可理解路径

只保留完成核心任务需要的操作。支线功能、反复试错和无关设置可以拆成另一条视频。

关键反馈

表单保存、任务完成、部署成功或错误修复都要给观众足够时间看清界面变化，不能在结果出现前就切走。

边界与下一步

说明哪些条件会影响结果，用户接下来应当在哪里继续，而不是只用一句“快去试试吧”结束。

录屏剪辑中最需要判断的六类片段

片段 建议 原因
无意义加载 压缩或删除，必要时用短提示说明等待 观众不需要体验完整延迟
系统反馈 保留足够阅读时间 成功、失败和状态变化是演示证据
操作失误 删除，但检查前后界面是否连续 简单硬切可能造成鼠标或窗口瞬移
鼠标移动 只保留有指向作用的轨迹 无目的晃动会分散注意力
输入过程 普通文本可加速，关键值要能读清 用户需要知道输入了什么，而不是看完每个按键
口播解释 根据语义剪停顿，不只按静音阈值 强调与思考停顿可能承载信息

CreatorCut 把转写、时间线、签名剪辑方案、字幕和本地导出放进同一条工作流。计划可预览、可撤销，源媒体与项目留在用户设备。

录制和剪辑前的隐私检查

  • 关闭邮件、聊天、日历和系统通知，避免录入客户或同事信息。
  • 使用演示账户与合成数据，不要在视频中展示真实用户记录。
  • 隐藏 API Key、访问令牌、连接串、后台域名和内部工单。
  • 检查浏览器书签、自动填充、最近文件和终端历史。
  • 导出前逐帧检查弹窗、切换窗口和遮罩边缘，不能只依赖自动模糊。
源视频留在本机，不代表录进去的内容自动安全。隐私保护从录制前的环境准备开始。任何剪辑工具都不能替代演示账户、合成数据和人工复核。

常见问题

产品录屏中的等待时间都应该删除吗？

不应该。等待如果帮助观众理解系统反馈或异步过程，应保留必要时长；无意义加载和操作失误可以压缩或删除。

CreatorCut 能同时处理口播和录屏吗？

可以。产品面向已录好的口播与产品录屏，把转写、剪辑决策、字幕、配乐和本地导出放在同一工作流中。

录屏中的账号与客户数据会上传吗？

源视频不会上传，但创作者仍应在录制前隐藏敏感账号、客户数据、密钥和通知内容。
