01 / 智能后期

不是套模板，
而是读懂你在说什么。

AgentMesh-CreatorCut 面向已经录好的口播和产品演示。云端 Director 只接收经过你确认的结构化上下文，返回签名剪辑方案；本地客户端负责真正处理媒体。

01 — TRANSCRIBE

中英混合口播，也能转得明白

本机运行 whisper.cpp，支持中文、英文、自动识别和混合模式。你可以先校对文本，再让 Director 做剪辑判断。

02 — DECIDE

交互式卡片，把模糊要求问准确

节奏、字幕、音乐和风险操作由 Agent 用结构化卡片确认。宿主不支持原生控件时，仍有语义一致的文本回退。

03 — FINISH

轻快配乐，不再是一段嗡嗡声

MVP 提供两套经过试听验收的轻快节奏模板；原声优先，背景音乐按响度边界混合。

04 — EXPORT

保持原色。没有偷偷加滤镜。

默认不做自动调色、LUT、HDR 转 SDR 或强制色域转换。预览确认后才应用，导出失败可以恢复，已有文件不会被静默覆盖。

06 / FAQ

先把重要的事说清楚。

会把我的视频上传到云端吗？

不会。源视频、音频、转写中间文件、预览和导出都留在本机。只有你检查并确认过的结构化 DirectorContext 才会发送给云端策略服务。

它会自动给视频加滤镜或调色吗？

不会。默认保持源视频色彩，不做自动 LUT、曝光增强、HDR 转 SDR 或强制 BT.709。任何受支持的画面处理都必须进入可见计划和本地预览。

升级会删除我的项目或 API Key 吗？

不会。项目和媒体不在安装目录，API Key 存在操作系统安全存储中。升级会先验证、构建和烟测，失败则恢复上一版本。

和 Lecturecast 有什么区别？

Lecturecast 从一个主题生成完整课程视频；AgentMesh-CreatorCut 从你已经录好的口播或产品录屏出发，做智能后期。
