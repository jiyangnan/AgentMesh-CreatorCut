01 / スマート編集

テンプレートではなく、
話の意味を理解する。

AgentMesh-CreatorCut は、撮影済みのトーク動画や製品デモから始めます。クラウド Director は承認済みの構造化コンテキストだけを受け取り、署名付き編集プランを返します。実際のメディア処理は公開クライアントがローカルで実行します。

01 — TRANSCRIBE

中国語、英語、混在音声に対応

whisper.cpp をローカルで実行し、中国語、英語、自動判定、混在モードに対応します。Director が編集判断を行う前に文字起こしを修正できます。

02 — DECIDE

対話カードで要件を正確に

テンポ、字幕、音楽、リスクのある操作を構造化カードで確認します。対応していない環境では同じ意味のテキスト表示に切り替わります。

03 — FINISH

低いノイズではなく、軽快な音楽

MVP には試聴済みの軽快なテンプレートを 2 種類収録。原音を主役に保ち、音楽は一定の音量範囲でミックスします。

04 — EXPORT

原色のまま。勝手なフィルターなし。

自動 LUT、トーンマップ、HDR から SDR への変換、色タグの強制は行いません。適用前にプレビューし、失敗した書き出しは再開でき、既存ファイルを黙って上書きしません。

02 / 製品境界

05 / FAQ

大切なことを、明確に。

動画はアップロードされますか？

いいえ。元メディア、音声、文字起こしの中間ファイル、プレビュー、書き出しはローカルに残ります。確認して承認した構造化 DirectorContext だけが戦略サービスへ送信されます。

自動でフィルターを追加しますか？

いいえ。デフォルトで元の色を保ちます。自動 LUT、露出補正、HDR から SDR への変換、BT.709 タグの強制はありません。

アップデートでプロジェクトや API Key が消えますか？

いいえ。プロジェクトとメディアはインストール先の外にあり、API Key は OS の安全なストレージに保存されます。更新に失敗した場合は以前の管理バージョンへ戻ります。

LectureCast との違いは？

AgentMesh-LectureCast はテーマから講座動画を生成します。AgentMesh-CreatorCut は撮影済みのトーク動画や製品デモから始め、スマートな後編集を行います。
