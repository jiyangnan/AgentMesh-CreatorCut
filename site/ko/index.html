01 / 스마트 편집

템플릿을 씌우는 것이 아니라,
말의 의미를 이해합니다.

AgentMesh-CreatorCut은 이미 촬영한 토킹헤드나 제품 데모에서 시작합니다. 클라우드 Director는 승인된 구조화 컨텍스트만 받아 서명된 편집 계획을 반환하고, 실제 미디어 처리는 공개 클라이언트가 로컬에서 수행합니다.

01 — TRANSCRIBE

중국어, 영어, 혼합 발화 지원

whisper.cpp를 기기에서 실행하며 중국어, 영어, 자동 감지, 혼합 모드를 지원합니다. Director가 편집 결정을 내리기 전에 전사 내용을 수정할 수 있습니다.

02 — DECIDE

대화형 카드로 요구사항을 정확하게

템포, 자막, 음악, 위험 작업을 구조화 카드로 확인합니다. 카드가 지원되지 않는 환경에서는 같은 의미의 텍스트 방식으로 전환됩니다.

03 — FINISH

웅웅거리는 소리가 아닌 경쾌한 음악

MVP는 청취 검증을 마친 경쾌한 템플릿 2종을 제공합니다. 원본 음성을 중심에 두고 음악은 제한된 음량 범위에서 믹스합니다.

04 — EXPORT

원본 색상 그대로. 몰래 넣는 필터 없음.

자동 LUT, 톤 매핑, HDR-SDR 변환, 색상 태그 강제를 하지 않습니다. 적용 전 미리보고, 실패한 출력은 재개하며, 기존 파일을 알리지 않고 덮어쓰지 않습니다.

02 / 제품 경계

지능은 클라우드에.

05 / FAQ

중요한 내용을 명확하게.

내 영상이 업로드되나요?

아니요. 원본 미디어, 음성, 전사 중간 파일, 미리보기, 출력물은 로컬에 남습니다. 직접 확인하고 승인한 구조화 DirectorContext만 전략 서비스로 전송됩니다.

자동으로 필터를 추가하나요?

아니요. 기본값은 원본 색상을 유지합니다. 자동 LUT, 노출 증가, HDR-SDR 변환, BT.709 태그 강제가 없습니다.

업데이트로 프로젝트나 API Key가 삭제될 수 있나요?

아니요. 프로젝트와 미디어는 설치 경로 밖에 있고 API Key는 운영체제의 안전한 저장소에 보관됩니다. 업데이트가 실패하면 이전 관리 버전으로 복원됩니다.

LectureCast와 무엇이 다른가요?

AgentMesh-LectureCast는 주제에서 강의 영상을 만듭니다. AgentMesh-CreatorCut은 이미 촬영한 토킹헤드나 제품 데모에서 시작해 스마트 후반 작업을 수행합니다.
